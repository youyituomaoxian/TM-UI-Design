机器状态色 · Machine States

机器主状态固定 5 类：生产 / 空闲 / 停机 / 故障 / 离线。状态 = 颜色 + 形状双通道（故障三角 / 离线空心环），色觉障碍、投屏、缩小后仍可辨；模式、生产子状态、停机原因只做第二层文字，不再新增颜色；状态点必须配文字，不能只靠颜色传信息。

形状 = 第二通道

故障用 三角（ISO 3864 警告形），离线用 空心环（无数据，与「已知的停止」形状对立）；两者在红绿色盲下与实心圆仍可区分——纯颜色做不到（生产↔故障在 deuteranopia 下 ΔE 仅 8.2）。

语义与 OEE

主状态类颜色形状含义OEE
生产.dot-run--state-run #16A34A实心圆自动/半自动且正在出件运行时间
空闲.dot-idle--state-idle #0891B2实心圆已开机、就绪但未生产空闲损失
停机.dot-stop--state-stop #64748B实心圆不生产，原因在第二层计划/非计划停机
故障.dot-fault--state-fault #F5222D三角故障/急停/报警停机非计划停机
离线.dot-offline--state-offline 环 #8290A3空心环通讯中断，不等于关机数据缺失

第二层 · 只加文字，不加颜色

自动 AUTO半自动 SEMI手动 MANUAL调机 SETUP休眠 SLEEP
换模缺料质量待判保养计划停机非计划停机关机
状态优先级：离线/心跳超时 > 故障 > 停机 > 生产/空闲；故障与离线不得归入“关机”，换模/调机不得归入“空闲”。详情/卡片显示「主状态 · 模式 · 原因」，如「停机 · 调机 · 换模」。
