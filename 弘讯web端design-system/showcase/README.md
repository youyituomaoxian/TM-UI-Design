# Showcase · 示例页

本目录存放**可直接打开的设计系统示例页**：用于评审、演示和对照，不是规范真源，也不参与生成链路。

| 文件 | 说明 |
|---|---|
| `弘讯亮色注塑机看板.html` | 独立示例：当前 `template.css` 内联 + 顶栏主题选择器；假数据演示。 |
| `web规范展示_框架版_20260806_1050.html` | **生成物**：由端目录根同名文件同步。 |
| `web规范展示_框架版_20260806_1050_分享版.html` | **生成物**：由端目录根非分享版生成，零外链。 |
| `表格规范展示_20261112.html` | **生成物**：由端目录根同名文件同步。 |

- **同步**：改根目录源后运行 `node scripts/sync-showcase.js`；`node scripts/verify.js showcase` 检查漂移。**不要手改三个规范展示副本。**
- **边界**：示例页保留模板示例树、演示文案与假数据，`validate-spec` 对 `showcase/` 豁免 `template.residue`；业务页必须替换品牌/底栏/作业树，不能照抄本目录文案。
- **路径**：非分享版通过 `../template.css` / `../assets/` 引用真源；分享版保持零外链。
- **打开**：浏览器直接打开即可，不依赖构建或网络。

> 端目录根仍保留同名规范展示作为源与现役人读入口；本目录是生成/示例副本。
