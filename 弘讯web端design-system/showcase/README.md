# Showcase · 示例页

本目录存放**可直接打开的设计系统示例页**：用于评审、演示和对照，不是规范真源，也不参与生成链路。

| 文件 | 说明 |
|---|---|
| `左右结构_v7_设备运维工作台.html` | **左右结构工作台示例（2026-11-19 定稿）**：`.shell/.rail` + 5 状态 + 表格/弹窗/图表；引用 `../template.css` / `../js/`；工具区由 `partials/shell-tools.html` 注入（本页不定义标准）。 |
| `左右结构_v7_设备运维工作台_分享版.html` | 上者的零外链分享版（`build-share-web.js` 生成），评审入口。 |
| `弘讯亮色注塑机看板.html` | **注塑机运行看板**：`.shell/.rail` + KPI + 台账/详情 + 状态色；由 v7 工作台派生；引用 `../template.css`。 |
| `弘讯亮色注塑机看板_分享版.html` | 上者的零外链分享版（`build-share-web.js` 生成）。 |
| `登录页示例.html` | **登录页示例（2026-11-20）**：按 RULES §1.1b 登录页规格自建（卡外 logo / 卡内标题组 / 账号密码 / 12 态中的默认+错误+找回 3 步+完成态）；含中英切换；引用 `../template.css` / `../assets/`。 |
| `登录页示例_分享版.html` | 上者的零外链分享版（`build-share-web.js` 生成）。 |

| `web规范展示_左右结构.html` | **左右结构规范展示**：默认进入 spec view，图表/状态/表格/弹窗一站评审；根目录同名文件为源。 |
| `web规范展示_左右结构_分享版.html` | 上者的零外链分享版。 |

- **生成物**：`web规范展示_左右结构*` 两件由根目录源经 `node scripts/sync-showcase.js` 生成；分享版由 `node scripts/build-share-web.js` 生成——**勿手改**，改源后重跑。
- **同步**：showcase 只保留新左右结构示例，不再有 V2.1 生成副本；`node scripts/verify.js showcase` 查规范展示副本漂移。
- **边界**：示例页保留模板示例树、演示文案与假数据，`validate-spec` 对 `showcase/` 豁免 `template.residue`；业务页必须替换品牌与作业树，不能照抄本目录文案。
- **门禁参与（按文件类型，不是整目录一刀切）**：源页过 `validate-spec` + 组件复用；含 `.rail` 的页跑作业树运行时；含 `.ws-tools` 的页比对外壳真源（`partials/shell-tools.html`）；分享版查零外链（清单见 `scripts/gate-manifest.json` → `newScope.shares`）。
- **路径**：非分享版通过 `../template.css` / `../assets/` 引用真源；分享版保持零外链。
- **打开**：浏览器直接打开即可，不依赖构建或网络。
