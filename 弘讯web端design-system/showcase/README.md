# Showcase · 示例页

本目录存放**可直接打开的设计系统示例页**：用于评审、演示和对照，不是规范真源，也不参与生成链路。

| 文件 | 说明 |
|---|---|
| `弘讯亮色注塑机看板.html` | 成品看板示例：当前 `template.css` 内联 + 顶栏主题选择器；假数据演示。 |
| `web规范展示_框架版_20260806_1050.html` | Web 规范活体展示（框架版）；从端目录根复制为示例副本，便于集中查看。 |
| `web规范展示_框架版_20260806_1050_分享版.html` | 同上，零外链分享版（内联 CSS）。 |
| `表格规范展示_20261112.html` | 表格规范活体展示；document 文档页，无 B 端框架。 |

- **边界**：示例页保留模板示例树、演示文案与假数据，`validate-spec` 对 `showcase/` 豁免 `template.residue`；业务页必须替换品牌/底栏/作业树，不能照抄本目录文案。
- **路径**：本目录内的非分享版页面通过 `../template.css`、`../assets/` 引用真源；分享版保持零外链。
- **打开**：浏览器直接打开即可，不依赖构建或网络。
- **维护**：样式改 `packages/web-ui/src/styles/` 后重建 `template.css`，再同步示例；不要在本目录手写第二套 token。

> 端目录根仍保留同名规范展示作为现役人读入口；本目录是示例副本。若确定去重，再删除根目录副本并全局改链。
