概览 · Overview

本页是弘讯 B 端 Web 设计系统全部视觉特征的活体展示。所有色值、字阶、间距、圆角、投影、动效、组件均直接取自 template.css 与 tokens.json 真源，未做任何硬编码近似。Agent 生成页面以本页为克隆源（cp page-template.html 新页面.html → 删 demo 内容、保留框架外壳）。

布局骨架（顶栏 72 / 侧栏 240 / 底栏 32）本身即本规范的固定滚动区规则 G8：html,body{overflow:hidden}，仅 .content 滚动。侧栏可点右下「收起」验证 G9 折叠。

页面级自造类守则 · RULES §7.9

平衡原则：约束「新原子」（token 级资产），放开「新结构」（布局/组合）。优先级铁律：组合 → 变体 → 页面级布局自造 →（禁）原子自造；非必要不自造；新增原子是兜底资源、不是自造许可。自造底线：颜色 var(--*) / 文字 .t-* / 动效 var(--motion-duration-*) / 4px 网格 / 禁 t- 前缀。
