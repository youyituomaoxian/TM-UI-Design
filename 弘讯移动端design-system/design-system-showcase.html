🟢 运行绿 · 跨端契约（Web / Mobile 共用 #16A34A）

为什么单独拆出运行绿

注塑机监控里「运行中 / 在线」是最高频出现的状态，必须第一时间被识别。把它从「成功」里拆成独立语义，避免与「任务完成」混淆。两端共用同一 HEX #16A34A——这是跨端唯一一致的绿色。

四语义 · 两套平台实现

语义Web 端移动端
成功#389E0D#10B981
警告#FA8C16#F59E0B
错误#F5222D#EF4444

C1
运行绿 #16A34A 两端必须完全一致唯一共用 HEX，禁止任一边改用其他绿。
C2
成功绿分治，禁止混用Web 用 #389E0D，移动端用 #10B981，两者不得互换。
C3
运行绿 ≠ 成功绿「设备运行中」用运行绿，「操作成功 / 任务完成」用成功绿，语义不可合并。
C4
移动端鲜亮色仅作填充徽标#10B981 / #F59E0B 只用于实心标签底 + 白字，不作白底文字（对比度不足）。

设计决策规则Rules & Golden Laws

⚡ 屏幕自动布局黄金法则（防溢出必读）
G1
画板与 Content 必须 FIXED 宽 375，Content 设 clipsContent=TRUE父框架不定宽，子元素一撑就溢出整页。
G2
任意内容列元素必须显式 width=343 + FIXED组件库默认 375，不手动改就撑破 16px gutter。
G3
纵向子节点用 counterAxisSizingMode，横向行用 primaryAxisSizingMode方向不同属性名不同，设错不生效。
G4
插入实例后立即复核实际 width ≤ 343Ardot 插入不继承父宽，默认 375 会静默撑大。
G5
横向行主轴对齐 SPACE_BETWEEN + 间距用 Token，总宽 ≤ 343标签按内容宽排 + 间距易超列宽（实测 354px 溢出）。
G6
带 padding 的框架插入实例后设 clipsContent=TRUE 兜底即便算错，视觉上也不会顶出画板。
G7
复合组件（卡片B+内部列表）Ardot 不可向实例内部插子节点 → 用外层 Frame 包裹为同级列表会被降级成兄弟节点，文档需标注此架构局限。
🔑 关键认知
组件库尺寸 ≠ 屏幕落位尺寸。组件规格里的 width=375px 是它在 Figma 独立画框里的全宽；在带 16px gutter 的真实屏幕里，落位宽必须是 343px。任何"把组件放进屏幕"的操作，第一步永远是：设 width=343 + FIXED，而不是先插再修。
